CME Hospitalar

Etiqueta para peróxido (PPH)

Etiqueta com indicador para esterilização por peróxido de hidrogênio, para materiais sensíveis ao calor.

Medidas em estoque
Fale com um especialista

Precisa de outra medida? Fale com o especialista

Uso

Aplique no invólucro antes do ciclo de peróxido. Confira a mudança de cor do indicador na liberação do material.

Características

Indicador específico para peróxido de hidrogênio. Adesivo próprio para invólucros de polipropileno (Tyvek®).

Diferenciais

Mesma rastreabilidade das etiquetas a vapor, para o processo de baixa temperatura.

Qual etiqueta usar com autoclave classe B?

A etiqueta duplo uso a vapor é indicada para autoclaves a vapor, incluindo classe B. Em caso de dúvida sobre o seu equipamento, fale com um especialista.

A fita indicadora deixa resíduo no pacote?

Não. O adesivo foi desenvolvido para ser removido sem deixar resíduo em tecido, papel crepado ou SMS.

As etiquetas atendem à RDC-15?

As etiquetas apoiam o registro de rastreabilidade exigido pela RDC-15 para processamento de produtos para saúde.
